Interpretable deep learning framework for pneumonia detection using ResNet18 and Grad-CAM on chest X-ray images.

# 🫁 Pneumonia Detection using ResNet18 with Explainable AI (Grad-CAM)

## 📌 Overview
This project presents an interpretable deep learning framework for automatic pneumonia detection from chest X-ray images. The system combines transfer learning with Grad-CAM visualization to provide both high accuracy and model transparency.

---

## 🚀 Key Features
- Baseline CNN model for comparison
- Transfer Learning using ResNet18
- Grad-CAM for visual explanation
- Confusion Matrix evaluation
- High sensitivity for pneumonia detection

---

## 📊 Results

| Model        | Accuracy |
|-------------|---------|
| Baseline CNN | ~79.33% |
| ResNet18     | **85.90%** |
